# Fonts

| File | Family | Source | Licence |
|---|---|---|---|
| `archivo-variable.woff2` | Archivo (variable, latin subset) | Google Fonts, fonts.gstatic.com | SIL Open Font License 1.1 |
| `archivo-narrow-variable.woff2` | Archivo Narrow (variable, latin subset) | Google Fonts, fonts.gstatic.com | SIL Open Font License 1.1 |

Both faces are self-hosted and served from this directory; the page loads no external font
stylesheet. Archivo is a grotesque drawn for high-performance print and signage, with the
squared terminals and tabular lining figures a work-order form needs. Archivo Narrow carries
the ruled field labels and stage names, where a form's labels are always condensed.
